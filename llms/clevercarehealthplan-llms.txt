# Clever Care Health Plan FHIR API

> Clever Care Health Plan is a California Medicare Advantage (HMO and HMO C-SNP) plan blending Eastern and Western medicine for seniors. It publishes an HL7 FHIR R4 API implementing the CMS Interoperability and Patient Access final rule (CMS-9115-F): a secured (SMART-on-FHIR OAuth 2.0 / OpenID Connect) Patient Access API and public (rate-limited) Provider Directory and Drug Formulary APIs, served on WSO2 Open Healthcare. ExplanationOfBenefit conforms to CARIN Blue Button (C4BB).

## APIs
- [FHIR R4 base URL](https://fhir.clevercarehealthplan.com/r4): resource endpoints (application/fhir+json)
- [CapabilityStatement](https://fhir.clevercarehealthplan.com/r4/metadata): FHIR 4.0.1 server metadata
- [SMART configuration](https://fhir.clevercarehealthplan.com/r4/.well-known/smart-configuration): OAuth 2.0 / OIDC discovery
